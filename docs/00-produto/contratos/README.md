# Contratos canônicos

Contratos transversais aprovados devem ser registrados aqui ou referenciados para o arquivo de código que os implementa. Alterações exigem proposta SDD, consumidores mapeados, snapshot, rollback e testes.

Nesta etapa, a regra transversal está registrada em `docs/04-arquiteto/propostas/regras-kgr-formacao-de-artigos.md` e implementada de forma aditiva nos contratos reais de `lib/arquiteto/contracts.ts`, `lib/marca/site-contracts.ts` e `lib/editorial/operational-flow.ts`. Os arquivos `unidades-editoriais.md`, `importacoes.md` e `versionamento.md` ainda não existem neste checkout.
